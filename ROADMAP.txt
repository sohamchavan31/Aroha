======================================================================
0. DESIGN RULES (apply to every screen)
======================================================================
  - Matte dark look. No gradients, shimmer, glows or coloured shadows.
  - Ivory (#EBE7DE) = the ONE main action button on a screen. Nothing else.
  - Muted brass (#C4A46A) = evolution stage and EP only. Nothing else.
  - Fonts: Unbounded = brand, stage names, screen titles
           Barlow Condensed = every number (kcal, kg, reps, EP)
           Manrope = all other text
  - Macro colours: kcal amber, protein lavender, carbs teal, fat rose,
    water sky, success green.
  - Spacing in multiples of 4. Use tokens from src/constants/theme.js.
  - Reuse src/components/ui/ (Card, Sheet, Chip, Field, PrimaryButton,
    IconButton, ProgressRings, SegmentBar, MacroBar). Don't restyle by hand.
  - Haptics: tap() for small actions, press() for main button,
    success() for mission done / PR / food added.
  - Every list needs a loading skeleton and a friendly empty state.
  - Mockup reference: https://claude.ai/artifact/Ff6pQcgo63oRDT5HydMXwY

2. BUGS AND LOGIC FIXES FOUND (do soon, small)
======================================================================
  [ ] Day streak never changes.
        User.streak exists but nothing in the backend ever updates it.
        Add: on first activity of a day (food log, mission, workout, water),
        streak +1 if last active day was yesterday, reset to 1 if older.
        Store lastActiveDate on User.
  [ ] Water goal ignores the user's setting.
        WellnessController /water/add uses ?goal default 8 and /water/remove
        hard-codes 8 when creating today's row. Use user.waterGoalGlasses.
  [ ] Generated sessions don't record weights or per-exercise sets, so they never
        feed exercise history or PR detection. Let the live session log each
        set (kg x reps) through /workouts/log, then show "Last" per exercise.
  [ ] Persist WorkoutLog.newPR (currently @Transient) so PR tags survive.
  [ ] Mission categories are STRENGTH / DISCIPLINE / RECOVERY / NUTRITION.
        Missions are never auto-completed: link them to real actions
        (food logged -> NUTRITION, workout saved -> STRENGTH, etc.)
        instead of manual tap only.
  [ ] AuthContext keeps the user object from login forever.
        Refresh it from /profile on app start so name/stage/avatar stay current.
  [ ] client.js production API URL is still a TODO (needed before release).
  [ ] Sleep reminder toggle in Settings had no scheduler behind it; it now shows
        "Coming soon". Add scheduleSleepReminder() in utils/notifications.js.
